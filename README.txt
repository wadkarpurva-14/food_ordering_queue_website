FOOD ORDERING QUEUE SYSTEM WEBSITE

Files:
- index.html: complete responsive website (HTML, CSS, JavaScript in one file)

How to run:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. Use Place Order to add an order, Process Order to serve the oldest pending order, and View Pending Orders to inspect the queue.

Features:
- Circular-queue behavior with a maximum of 5 pending orders
- FIFO processing
- Dashboard counts for total, pending, and processed orders
- Custom food items
- Browser localStorage persistence
- Reset confirmation
- Responsive desktop and mobile layout

This is a front-end demo. It does not include a backend, user accounts, online payments, or multi-device synchronization.
