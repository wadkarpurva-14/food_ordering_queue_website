About the Queue System

This Food Ordering Queue System is a small browser-based project inspired by a C program using a circular queue. It helps a restaurant accept orders, maintain the order sequence, and process the oldest waiting order first.

＋ Enqueue

Place a new order at the rear of the queue.

⚙ Dequeue

Process and remove the order at the front.

↻ Circular queue

Freed queue slots can be reused. Maximum pending orders: 5.

How it works

  1. Enter the customer's name, food item, and quantity.
  2. The order is added to the end of the pending queue.
  3. Process Order completes the oldest pending order.
  4. Order counts and the pending list update automatically.
Demo note: orders are saved in this browser using local storage. This is a front-end demo, not a live online ordering or payment service.
